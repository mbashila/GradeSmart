# Assets Directory

This directory should contain the following image assets for the GradeSmart app:

## Required Assets

1. **icon.png** (1024x1024px)
   - App icon displayed on the home screen
   - Should feature the GradeSmart logo (green book with checkmark)

2. **splash.png** (1242x2436px recommended)
   - Splash screen image shown when the app launches
   - Should match the app's branding

3. **adaptive-icon.png** (1024x1024px)
   - Android adaptive icon foreground
   - Should be a simple, recognizable icon

4. **favicon.png** (48x48px)
   - Web favicon for PWA support

## Creating Placeholder Assets

You can create simple placeholder images using any image editor or use online tools. For development purposes, you can use solid color images or simple text-based images.

## Icon Design Guidelines

- Use the primary green color (#4CAF50) as the main color
- Include a book or document icon
- Add a checkmark or grading symbol
- Keep it simple and recognizable at small sizes
- Ensure good contrast for visibility
